## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Vishnunair585/My_portfolio.git
```

Move into the project folder:

```bash
cd My_portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Deploy:

```bash
npm run deploy
```
